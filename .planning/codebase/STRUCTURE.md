# Directory Structure

## Root
- `src/app`: Routing and layout logic.
- `src/components`: Reusable UI modules.
- `src/lib`: Core utilities and SDK clients.
- `src/data`: Static configuration and fallback data.
- `src/services`: API abstraction layers.
- `src/config`: Site-wide constants (navigation, SEO).

## Specialized Folders
- `rockseo/`: Internal engine for hyper-local page generation.
- `__tests__/`: Unit and component test suites.
- `.planning/`: Context preservation and assistant specs.
- `public/`: Assets (images, fonts, static sitemaps).
