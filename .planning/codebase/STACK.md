# Technology Stack

## Core Framework
- **Next.js 16.1 (Turbopack)**: High-performance React framework with App Router.
- **React 19.2**: Concurrent rendering and latest React features.
- **TypeScript 5**: Primary language for type-safe development.

## UI & Styling
- **Tailwind CSS 4**: Utility-first styling with modern PostCSS pipeline.
- **Framer Motion 12**: Advanced animations and transitions.
- **HeroUI & Radix UI**: Accessible and premium component foundations.
- **Lucide & Healthicons**: Unified iconography for clinical aesthetics.

## Content & Data
- **Directus SDK 21**: Headless CMS for dynamic medical and service data.
- **Zod**: Schema validation for API responses and configuration.
- **Next Themes**: Dark/Light mode management.

## SEO & Analytics
- **Next-Sitemap**: Automated XML sitemap generation.
- **Next-SEO**: Structured metadata and OpenGraph management.
- **RockSEO**: Custom in-house SEO generation engine.
